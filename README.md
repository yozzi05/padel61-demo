# Padel 61 — демо цифровой платформы клуба

Интерактивная демо-версия: бронирование кортов, тренировки, рейтинг игроков, матчи, поиск игры, турниры и личный кабинет.
Без backend: все данные — mock, состояние пользователя хранится в `localStorage` (ключи `p61.*`).

## Запуск

Сборка не нужна. Нужен любой статический сервер (ES-модули не работают через `file://`).

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Откройте http://localhost:5173. Подойдёт и `npx serve .`, `python -m http.server`, GitHub Pages и т.п.
Маршрутизация через hash (`#/players/ivan-petrov`), поэтому серверные rewrite-правила не нужны.

## Стек

- **Preact + htm** (`src/lib/preact-htm.js`, 13 КБ) — React-совместимый API хуков, шаблоны без сборки.
  Перенос на Vite + React: заменить `src/lib/html.js` и переписать шаблоны `html\`...\`` в JSX — структура и хуки те же.
- Чистый CSS с дизайн-токенами, без UI-библиотек.
- Шрифты: **Archivo** (заголовки, цифры) + **Manrope** (интерфейс).
  В Google Fonts Archivo не содержит кириллицы, поэтому кириллические глифы заголовков берутся из **Roboto Flex**
  с той же осью ширины (`font-stretch`), латиница и цифры остаются в Archivo.

## Структура

```
src/
  app/          App (маршруты), store (Context + localStorage)
  components/   ui-примитивы, иконки, графика корта, layout (header, bottom nav, footer)
  features/
    booking/    выбор даты/корта/слотов, checkout, экран успеха
    courts/     live-табло «Корты сейчас»
    coaches/    расписание тренеров (mock)
    matches/    табло матча, билет заявки «Найти игру», история игрока
    tournaments/ сетка, групповые таблицы, участники
    gamification/ достижения, XP, серии
    profile/    демо-вход, карточка брони
  pages/        по файлу на маршрут
  data/         club, courts, coaches, players, matches, openGames, tournaments, achievements, bookings
  hooks/        reveal, count-up, parallax, clock
  lib/          роутер, даты, форматирование, расписание (детерминированный mock), storage
  styles/       tokens → base → layout → components → страницы
```

## Данные

- **Реальные (padel61.ru):** название, адрес, телефон, email, режим 07:00–22:00, Telegram/Instagram, управляющая,
  типы кортов и цены (3 000 ₽/ч, Single — 1 000 ₽/ч), 7 тренеров (категории, страны, языки, уровни, цены индивидуальных
  и групповых занятий), форматы турниров (MIXED — 12 000 ₽, PRO AM — 15 000 ₽), аренда ракеток, мячи, парковка,
  сертификат от 10 000 ₽, фото тренеров и клуба.
- **Демо:** количество кортов (по одному каждого типа), занятость расписания, 28 игроков и рейтинг, матчи, заявки,
  конкретные турниры и результаты, достижения. Даты считаются от текущего дня, поэтому демо не устаревает.
- Дополнительные фото — Unsplash (бесплатная лицензия).

## Демо-сценарии

1. Главная → «Корты сейчас» → «Забронировать» → слот → оплата (100% или 50/50) → бронь в кабинете.
2. «Найти игру» → «Присоединиться» (места уменьшаются) или «Создать заявку».
3. Турнир PADEL 61 CUP → «Участвовать» → выбор партнёра.
4. Рейтинг → профиль игрока → график рейтинга, матчи, достижения.
5. Кабинет: вход по телефону (любой код), вкладки, отмена брони, сброс демо-данных в «Настройках».

Флажок «Демо: имитировать отказ банка» в checkout показывает состояние ошибки оплаты.
